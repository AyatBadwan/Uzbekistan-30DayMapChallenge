# 🔵 Day 2: Lines Map - Mountainous Hiking Trails Network (Uzbekistan)

## 📌 Project Overview
This project focuses on lines mapping and geospatial big data analytics in Uzbekistan. It visualizes the massive network of active paths, backcountry tracks, and rugged hiking trails winding through the country's iconic mountainous terrains.

The spatial data reveals heavy structural concentrations wrapping around the gorgeous **Ugam-Chatkal State National Natural Park** east of Tashkent.

## 🛠️ GIS Workflow & Tech Stack
- **Data Source:** OpenStreetMap (Live network query via Overpass Turbo API)
- **Data Format:** Spatial Network Vector Dataset (`export.geojson` - 10.1 MB)
- **Visualization Platform:** Kepler.gl Framework
- **Cartographic Base Layer:** High-resolution Satellite Terrain Imagery for realistic geographical context

## 📂 Deliverables in this Folder
- `day02_hiking_trails..png`: The final high-resolution cartographic map rendition with a proportional length legend.
- `export.geojson`: The raw extracted geospatial big data file containing over 8,800 active path features.
