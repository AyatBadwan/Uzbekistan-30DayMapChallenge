# 🇺🇿 Uzbekistan - #30DayMapChallenge 🗺️

Welcome to my official repository for the global **#30DayMapChallenge**. This project is a dedicated spatial exploration of **Uzbekistan**, combining open-source geospatial data querying, data engineering, and premium cartographic styling to showcase the country's rich history, environmental patterns, infrastructure, and urban geography.

The repository is structured dynamically into daily standalone modules, each exploring a unique cartographic theme—ranging from basic vector geometries (Points, Lines, and Polygons) to advanced spatial analysis and custom rendering layouts.

---

## 🛠️ Global Tech Stack & Workflow
* **Data Sourcing & Querying:** OpenStreetMap (OSM) data extracted using the **Overpass Turbo API** to fetch precise localized features.
* **Geospatial Processing:** Python programming (`folium`, data manipulation packages) alongside standard vector formats like **GeoJSON** and interactive web assets.
* **Cartography & Rendering:** Immersive 3D and 2D canvas designs built primarily using platforms like **Kepler.gl** over **Mapbox** dark-matter engine templates for dynamic, modern visual hierarchy.

---

## 📂 Repository Structure
Each folder inside this repository represents a specific day of the challenge and contains:
* 📁 Raw spatial vector datasets (`.geojson`, `.py` scripts, or web layouts).
* 🖼️ High-resolution exported map graphics or interactive deployments.
* 📄 A dedicated local `README.md` documenting the tools and steps used for that specific map.
